# Harshit Rawat Portfolio

Personal portfolio website for Harshit Rawat, a student software developer focused on Minecraft plugin and mod development, Python projects, automation, and web development.

## Tech Stack

React, TypeScript, GSAP, Three.js, WebGL, HTML, and CSS.

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
